`main.tex` is an English research draft incorporating the completed five-seed
study and its negative results. `references.bib` contains only records checked
against primary arXiv/publisher/conference sources on 2026-10-21. The source
links and verification scope are listed in `bibliography-verification.json`.
This is a scoped literature review, not a claim of exhaustive prior-art search.

Regenerate tables and figures from persisted source CSV/JSON:

```bash
cd /workspaces/AlgoLearning/ucgnn-paper-study
PYTHONPATH=src /workspaces/AlgoLearning/distributed-coloring-learning/.venv/bin/python -m dcl.paperstudy.report
.tools/tectonic -X compile --keep-logs paper/ucgnn/main.tex
```

Compiler: Tectonic 0.17.0, downloaded locally from the official release:
https://github.com/tectonic-typesetting/tectonic/releases/tag/tectonic%400.17.0
The `x86_64-unknown-linux-musl.tar.gz` archive was verified against the release
API SHA256 `8533d07f9ccbd7a65824b9e0459041bca34af1eb33daba48f59215593753a3b7`
before extracting the binary to ignored `.tools/tectonic`. The compiler may
download TeX package/font resources on first use. An existing LaTeX/BibTeX
installation can instead compile the same sources. The generated PDF is kept;
intermediate files and downloaded tools are ignored.
