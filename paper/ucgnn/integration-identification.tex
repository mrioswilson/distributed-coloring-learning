\paragraph{Native support and a chosen extension.}
Let $\mathcal X_T$ be the admissible rooted COMMIT inputs for a fixed
interface, $\mathcal N_T\subseteq\mathcal X_T$ its native-message support,
and $\mathcal H$ a class of binary local rules. A finite observed bank
$\widehat{\mathcal N}_T\subseteq\mathcal N_T$ is a different object.
\begin{proposition}[Native-support underdetermination]\label{prop:support}
If $g_0,g_1\in\mathcal H$ agree on $\mathcal N_T$ and differ at an
admissible $x^\star\notin\mathcal N_T$, even complete native input/label
observations cannot uniquely identify their extension to $\mathcal X_T$.
For the implemented BE KW, GM color and Greedy rules, native messages
satisfy $O_T=p_v$. Thus, whenever $\mathcal H$ contains both
$g_0=p_v$ and $g_1=E_vp_vF_v(c_v)$ and a legal active occupied query exists,
the stated ambiguity occurs.
\end{proposition}
\begin{proof}
Both rules induce identical labels on every possible native input, hence
identical native observation laws. Their different answers at $x^\star$
cannot be selected from those observations alone. For the named teachers,
each native participating color root is eligible and chooses a free option;
a nonparticipating root has target zero. Therefore $O_T=p_v$ natively.
In the worked KW state, active option~3 is occupied: $g_0=1$ and $g_1=0$.
A full exact prefix also reaches these values on a star with legal IDs
$(6,3,0,1)$: both point reductions choose point~0 and preserve these
constant-polynomial values; all KW steps before bound~7 leave them unchanged.
A scheduled GM/Greedy root adjacent to an already colored vertex similarly
admits the query of that occupied color. These queries are allowed by the
contract but are not native proposals.
\end{proof}
This is an elementary support argument, not a new impossibility theorem for
restricted hypothesis classes or learning algorithms. A restrictive prior
can select an extension. We specify $O_T$ as our reference contract; we do
not infer a teacher's unique off-support intention. The empirical agreement
results concern $\widehat{\mathcal N}_T$, not exhaustive native support.
